# Consentimento Web Push `1.0.0`

Status: aprovado pelo responsável pelo projeto em 26/11/2026 para implementação controlada; uso real condicionado à avaliação e aprovação do aviso aplicável ao piloto e aos gates da ADR 0022; revisão jurídica integral antes da abertura pública.

## Texto

> Receba notificações quando novos artigos em português forem publicados. Não é necessário criar uma conta. Você poderá cancelar sua inscrição a qualquer momento. Consulte o aviso de privacidade.

## Contrato semântico

| Campo | Valor ou requisito |
| --- | --- |
| `consentVersion` | `1.0.0` exato; a API não deve aceitar somente uma versão sintaticamente válida. |
| `purposeId` | `new-articles-pt-br` estável. |
| `privacyNoticeVersion` | `1.0.0` exato, correspondente ao aviso exibido; qualquer mudança material exige nova versão. |
| Finalidade | Notificar artigo novo PT-BR depois de publicação confirmada. |
| Ação afirmativa | Controle desmarcado por padrão ou botão inequívoco, acionado pelo titular após exibição do texto e link do aviso. |
| Permissão do navegador | Solicitada somente depois da manifestação informada e de gesto do titular; não constitui sozinha consentimento LGPD. |
| Validade | 365 dias a partir do instante aceito pelo servidor. |
| Renovação | Novo consentimento explícito; nunca automática. |

## Evidência mínima

A prova deve ser associada a uma geração da inscrição e conter:

- `consentId` opaco e aleatório;
- `subscriptionId` pseudonimizado e `subscriptionGeneration`;
- `purposeId` e `consentVersion` exatos;
- `consentGrantedAtUtc` definido ou confirmado pelo servidor em UTC;
- `expiresAtUtc = consentGrantedAtUtc + 365 dias`;
- `locale = pt-BR`;
- referência imutável ao texto e à versão do aviso exibido;
- método de manifestação, limitado a uma enumeração sem user agent livre;
- instante de revogação, expiração ou substituição, quando ocorrer.

Não usar IP, fingerprint, nome, e-mail, user agent completo ou telemetria comportamental como prova padrão. O registro operacional pode ser atualizado, mas a evidência do consentimento não pode ser sobrescrita. O prazo de conservação da prova após o fim da inscrição depende de decisão jurídica e deve ser limitado ao necessário.
